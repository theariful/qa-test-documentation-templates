## 5. Entry Criteria

- [ ] Requirements reviewed and frozen
- [ ] Build deployed to the QA environment and smoke-passed
- [ ] Test cases written and reviewed
- [ ] Test data prepared
- [ ] Environment stable and accessible

## 6. Exit Criteria

- [ ] 100% of planned test cases executed
- [ ] No open Critical or High severity defects
- [ ] All Medium defects triaged with an agreed disposition
- [ ] Regression suite passed
- [ ] Test summary report published and signed off

## 7. Suspension and Resumption

**Suspend testing when:** the build is unusable, a blocker prevents more than 30% of cases from running, or the environment is down.

**Resume when:** a fixed build is deployed and re-smoke-tested.
